Quick guide

Reading Sightline

Clear means the path clears mapped terrain and objects. Foliage means trees intersect the path. Blocked means terrain or a building obstructs it. Unknown samples stay separate.

Radio mode adds Earth curvature and Fresnel clearance. Heights are meters above local ground (AGL). The viewshed samples rays on a grid, so a smaller step is more detailed and slower.

The static release downloads global ground elevation from AWS Terrain Tiles, buildings from OpenFreeMap/OpenMapTiles, and Meta/WRI satellite canopy from Source Cooperative. The local Python edition can use higher-detail USGS 3DEP/LiDAR in the United States. Missing source coverage remains unknown and is disclosed in the result notes.

Install on mobile: use your browser's Add to Home Screen or Install App command. Once opened online, the app shell and bundled starter area can launch offline; downloading data for a new location still requires internet access.

Satellite tiles are a visual reference only. Export KML to inspect the path in Google Earth.
